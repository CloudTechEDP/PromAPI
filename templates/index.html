PromAPI — The ultimate Prometheus API

Projeto Open Source para consolidar o envio de metricas para o prometheus

juntando as funcoes do pushgateway e do Aggregation gateway em um sistema unico.

simples de usar e simples para persistência dos dados


Aggregate Metric

Descrição: Agregador de valores, novos valores serão somados à métrica existente.

Exemplo CURL (Clique para Copiar):

echo "aggregate_total{type="counter", label1="job", label2="instance"} 1" | curl --data-binary @- http://172.21.10.15:8001/metrics/job/aggregate/myjob

Counter Metric

Nome: Counter Metric

Type: counter

Descrição: Uma métrica cumulativa que só pode aumentar ou ser redefinida para zero. Ideal para contagem de requisições ou erros.

Endpoint: http://example.com/metrics/job/counter/myjob

Exemplo CURL (Clique para Copiar):

echo "simple_counter_total{label1="job", label2="instance"} 1" | curl --data-binary @- http://172.21.10.15:8001/metrics/job/counter/myjob
Gauge Metric

Nome: Gauge Metric

Type: gauge

Descrição: Uma métrica que representa um único valor numérico que pode aumentar ou diminuir arbitrariamente. Ideal para temperatura, uso de memória ou contagem de usuários ativos.

Endpoint: http://example.com/metrics/job/gauge/myjob

Exemplo CURL (Clique para Copiar):

 echo "gauge_metrics{label1="job", label2="instance"} 17" | curl --data-binary @- http://172.21.10.15:8001/metrics/job/gauge/myjob
